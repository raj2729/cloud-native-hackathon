# Project review standards

This repository currently contains a React 19 + Vite conference website in `frontend/`. Its UI combines React components (`src/App.jsx`, `src/LegacyPage.jsx`) with legacy Bootstrap-style markup and CSS. Static images and fonts live under `frontend/assets/`; `frontend/dist/` is generated output.

Apply the React standards to current frontend code. Apply the Node.js standards only to Node.js backend code when it is introduced or changed; do not assume a backend, framework, database, or API exists today.

Report actionable regressions introduced by the pull request. Do not present pre-existing patterns or style-only suggestions as findings.
